# Ichnora brand kit

**Ichnora** (IK-nor-ah), from Ancient Greek *íchnos* (ἴχνος): *track, footprint, trail*.
**Tagline:** Every call leaves a footprint.

## What the mark means
- **The dot** is today's call: the signal we publish.
- **The fading steps below it** are past calls. Each one leaves a footprint you can trace back.
- **The lime → cyan gradient** is that track over time: from called to graded.

Together: every prediction is published, tracked and graded in public.

## Colours
| Role | Hex |
|---|---|
| Lime (start, primary accent) | `#D4FF3A` |
| Cyan (end) | `#3DE8FF` |
| Ink (glyph, backgrounds) | `#0B0B0F` / `#07070A` |
| Paper (light backgrounds) | `#F7F6F1` |
| Text on dark | `#F4F4EF` |

Gradient: 135°, `#D4FF3A` → `#3DE8FF`.

## Rules
- Keep the glyph ink-dark on the gradient. Don't put the gradient behind text you need to read.
- Use solid lime below 32px.
- Font: **Bricolage Grotesque ExtraBold** for the wordmark and headlines; **Inter** for text; **JetBrains Mono** for numbers and labels.
