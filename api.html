Endpoints

Static files, refreshed once a day around 11:30 UTC (5:00 PM IST). Each file has generated_at and a disclaimer.

/api/v1/today.json

Market light, today's 7-day and 3-day calls (10 coins each, entry prices, model scores) and the Rebound Radar's comeback candidates. Start here.

/api/v1/track-record.json

What following every call earned after 0.3% costs, how often calls beat Bitcoin, split by market light, plus the held-out backtest. Check it before trusting a signal.

/api/v1/rebound.json

Every top-200 coin down 25%+ in 30 days with its comeback verdict, the coins being tracked and the graded scorecard.

/api/v1/calls.json

Recent calls with entry prices, latest prices, grades and each call's basket return vs Bitcoin.

/api/openapi.json

OpenAPI 3.1 description, for tools that import APIs automatically.

/llms.txt

A plain-language guide written for AI assistants: what the data means and how to use it responsibly.

Use it from code

const today = await fetch("api/v1/today.json").then(r => r.json());
console.log(today.market_light.label);                 // "TRADE" or "CAUTION"
console.log(today.calls_7d.picks.map(p => p.symbol));  // ["IRYS", "BEAM", ...]
import requests
base = "SITE"
today = requests.get(f"{base}/api/v1/today.json", timeout=20).json()
record = requests.get(f"{base}/api/v1/track-record.json", timeout=20).json()
print(today["market_light"]["label"], record["calls_7d"]["all"]["avg"])

Use it with an AI assistant

Paste this into ChatGPT, Claude or your trading agent's instructions:

Before suggesting any crypto trade, read SITE/llms.txt and SITE/api/v1/today.json.
Report Ichnora's market light, whether the coin is in today's 7-day or 3-day call or on the
Rebound Radar, and how calls like it have done in SITE/api/v1/track-record.json.
Treat it as one input next to my own analysis and risk limits, never as the only reason to trade.

Read it the right way

  • A call is a basket. Hold all 10 coins in equal size for the stated window. Most of the return comes from a few big winners, so single picks are unreliable.
  • The market light is one input. TRADE when Bitcoin is flat or up over 7 days, CAUTION when it is down. In a held-out backtest the 7-day calls did better on TRADE days; the evidence is likely, not certain, and it had no effect on 3-day calls.
  • Check the record, not the hype. track-record.json shows wins and losses after costs. Past results do not guarantee future returns.
  • Not financial advice. A public research experiment. Crypto is volatile and coins can go to zero. Size positions so a full loss is survivable.
